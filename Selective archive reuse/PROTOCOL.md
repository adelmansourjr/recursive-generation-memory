# When does a sequence learner trust the wrong archive?

## Research question

A verified archive can help a learner recognise a returning source, but a source can return with different behaviour in rare contexts. Test whether an autoregressive sequence model learns to reuse archived information prefix by prefix without widening the gap on genuine returns. The prior categorical study used one potential archive and oracle context IDs. Here state comes from the preceding two generated tokens, the learner sees three competing verified archives, and one archive looks like a new source on common prefixes while disagreeing on rare ones.

## Generator, information and budgets

Generate fixed-length token sequences with source-specific trigram transitions. Each sequence starts with a shared random two-token prefix and then samples the next token and updates its state 14 times. The vocabulary has six symbols. A prefix is called rare if either of its two tokens belongs to the two deliberately infrequent symbols. The learner sees tokens only. The initial archives contain 160 sequences each from A, B and a separate decoy source. At each round all arms receive the same 20 fresh verified sequences. Every fitted recursive learner draws 48 length-matched sequences from its own previous forecast using the same random-number schedule across arms. Learners fit conditional probabilities from sequence transition counts. The current verified estimator contributes 16 pseudo-counts per prefix row; the remainder comes from the generated sequences. Generated transitions never update the verified archives or change-point likelihood. The verified-only controls use the same 20 fresh sequences and omit the generated term.

Evaluate six families: no shift; abrupt return to an archived source; abrupt partly changed return (archived head, new tail); return to a new source whose head matches the wrong archive; gradual shift to that new source; return to a previously encountered but unarchived source. Source distributions, timings, initial archived source, and archive identities are unavailable to learners. Within-world pairing uses the same real observations, initial generation model and simulation randomness. There are 48 development worlds and 128 confirmation worlds per family, with different seeds and freshly drawn sources.

## Methods

Fit a cumulative count estimator, tuned rolling window, exponential forgetting, recent-window likelihood retrieval with either global or prefix-specific archive weights, and Bayesian online change-point detection with either diffuse resets or a mixture of complete archives. All archive-aware methods have the same snapshots. The proposed gated reset learns, at each candidate change point, both which archive is relevant and which prefix rows are consistent with that archive. The per-prefix indicator has a fixed Bernoulli prior. Integrating the two hypotheses (archive or diffuse) yields an exact marginal likelihood and next-token mixture for that row given a candidate segment and archive source. The indicator is shared across the observations in that segment and prefix row. Priors and masks do not read evaluator metadata.

Hyperparameters are chosen on development worlds using 50% equal-family, whole-stream population excess KL and 50% mean early rare-prefix KL across partly changed and wrong-archive returns. The best non-candidate family by this same rule is the fixed primary reference. Score all methods and both training arms on the uninspected confirmation worlds; keep the validated hyperparameters fixed. Effects are under equal verified/recursive exposure, not equal predictor calculation time.

## Inference

Primary endpoint: mean rare-prefix conditional next-token KL across the first eight rounds after return, equally weighted across partial and wrong-archive families, comparing gated reset with the validation-selected reference. Score each true finite sequence process exactly by propagating its prefix-state probabilities across all 14 prediction positions. The useful-effect threshold is a reduction of 0.010 nats with a positive lower bound on a 95% paired stratified bootstrap interval. The population safeguard is that the upper bound for the gated-reset increase in all-round population KL, averaged across six families, is below 0.010 nats. Separately report the conjunction, ordinary-distribution return, gradual drift, rare-prefix mass and losses on novel recurrence, plus diagnostics by baseline and verified-only controls. Each bootstrap uses 10,000 resamples at the whole-world level, stratified by family; additional comparisons are descriptive rather than multiplicity-adjusted.

The candidate is an application of Bayesian model selection in a small sequence model. This does not establish robustness of neural language models, forgetting natural-language facts, or learning the unknown definition of a context from text. The synthetic process makes tail shifts exactly verifiable and is a test of the mechanism under known sample constraints.
